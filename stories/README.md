# YAML-Driven Storybook Stories

This directory contains the YAML-driven Storybook implementation for the Fluwy UI library.

## Directory Structure

```
stories/
├── yaml-driven/
│   ├── YamlRenderer.svelte              # Universal component renderer
│   ├── yaml-loader.ts                   # YAML schema loading utilities
│   ├── yaml-story-generator.ts          # Story generation utilities
│   ├── Introduction.stories.ts          # Getting started examples
│   ├── TestTheme.stories.ts            # Test theme demonstrations
│   ├── YamlSchemaLoader.stories.ts     # Schema format examples
│   ├── ComponentTesting.stories.ts     # Component test suites
│   ├── AutoGenerated.stories.ts        # Auto-generated examples
│   └── generated/                       # Auto-generated story files
│       ├── default.stories.ts          # From app/themes/default.yaml
│       ├── tests.stories.ts            # From app/themes/tests.yaml
│       └── storybook-tests.stories.ts  # From app/themes/storybook-tests.yaml
└── README.md                           # This file
```

## Quick Start

1. **Run Storybook with YAML generation:**
   ```bash
   npm run storybook:yaml
   ```

2. **Generate stories only:**
   ```bash
   npm run generate-yaml-stories
   ```

3. **Run standard Storybook:**
   ```bash
   npm run storybook
   ```

## Creating New Stories

### Manual Story Creation

```typescript
import type { Meta, StoryObj } from '@storybook/svelte';
import YamlRenderer from './yaml-driven/YamlRenderer.svelte';
import { YamlStoryGenerator } from './yaml-driven/yaml-story-generator.js';

const meta: Meta<YamlRenderer> = YamlStoryGenerator.createMeta(
  'My Category/My Component',
  'Description of my component tests'
);

export default meta;
type Story = StoryObj<YamlRenderer>;

export const MyStory: Story = YamlStoryGenerator.createStory({
  name: 'button',
  props: {
    text: 'My Button',
    variant: 'primary'
  },
  description: 'My button test'
});
```

### YAML Schema Creation

Create or modify YAML files in `app/themes/` and run the generation script:

```yaml
# app/themes/my-test.yaml
components:
  - name: "button"
    description: "My button test"
    props:
      text: "Test Button"
      variant: "primary"
      size: "md"
```

Then run:
```bash
npm run generate-yaml-stories
```

## YAML Schema Format

### Basic Component Schema

```yaml
components:
  - name: "component-name"
    description: "Component description"
    props:
      property1: "value1"
      property2: "value2"
```

### Theme-Based Schema

```yaml
colors:
  brand:
    DEFAULT: "#3b82f6"
    500: "#3b82f6"

forms:
  button:
    variants:
      brand: "bg-brand-500 text-white"

# This automatically generates button stories
```

### Complex Component Schema

```yaml
components:
  - name: "div"
    description: "Card component"
    props:
      class: "bg-white rounded-lg shadow-md"
      content:
        - h3:
            content: "Card Title"
            class: "text-xl font-bold"
        - p:
            content: "Card content"
        - button:
            text: "Action"
            variant: "primary"
```

## Features

- **Universal Rendering**: Any Fluwy component can be rendered via YAML schema
- **Theme Integration**: Full support for Fluwy's theme system
- **Auto-generation**: Stories generated automatically from theme files
- **Interactive Controls**: Edit schemas and themes in real-time
- **Error Handling**: Clear error messages for invalid schemas or unknown components
- **Documentation**: Automatic documentation generation from schema descriptions

## Tips

1. **Use the Introduction stories** to understand the basic concepts
2. **Check generated stories** for examples of auto-generated content
3. **Modify theme objects** in story controls to see real-time updates
4. **Use descriptive names** in your YAML schemas for better story organization
5. **Test edge cases** by creating stories with invalid or missing properties

## Troubleshooting

### Component Not Found
If you see "Component Not Found" errors:
1. Ensure the component is registered in the Fluwy app
2. Check the component name spelling in your YAML schema
3. Verify the component is exported from the appropriate index file

### YAML Parsing Errors
If YAML files fail to parse:
1. Check YAML syntax (indentation, quotes, etc.)
2. Validate your YAML using an online validator
3. Check the console for detailed error messages

### Stories Not Generating
If the generation script doesn't create stories:
1. Ensure YAML files are in `app/themes/` directory
2. Check that YAML files contain recognizable component definitions
3. Look for warnings in the script output
