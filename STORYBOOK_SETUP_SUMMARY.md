## 🚀 How to Use

### Quick Start
```bash
# Generate stories from YAML and start Storybook
npm run storybook:yaml

# Or run separately
npm run generate-yaml-stories
npm run storybook
```

### Creating Component Tests via YAML
```yaml
# app/themes/my-tests.yaml
components:
  - name: "button"
    description: "Primary button test"
    props:
      text: "Test Button"
      variant: "primary"
      size: "md"
```

### Manual Story Creation
```typescript
import { YamlStoryGenerator } from './yaml-driven/yaml-story-generator.js';

export const MyStory = YamlStoryGenerator.createStory({
  name: 'button',
  props: { text: 'Hello', variant: 'primary' },
  description: 'My button test'
});
```

## 🔧 Technical Architecture

### Component Flow
```
YAML Schema → YamlLoader → YamlRenderer → Fluwy Component → Rendered Output
```

### Story Generation Flow
```
Theme YAML → Script Parser → Component Extraction → Story Generation → TypeScript File
```

### Integration Points
- **Fluwy App**: Uses existing component registration system
- **Theme System**: Leverages existing theme loading and merging
- **Render System**: Uses existing Render component architecture

## 🎨 Unique Aspects

This implementation is unique because:

1. **No Traditional Stories**: Components tested via YAML configuration
2. **Schema-First**: YAML schemas serve as both tests and documentation
3. **Theme-Driven**: Automatic story generation from theme files
4. **Production Alignment**: Same rendering system as actual application
5. **Rapid Testing**: No manual story writing for basic component testing
